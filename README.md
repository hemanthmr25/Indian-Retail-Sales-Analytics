🛍️ Indian Retail Sales Analytics Dashboard
📌 Overview

This project is an end-to-end Business Intelligence dashboard built using Power BI, SQL, and DAX to analyze retail sales performance.

The dashboard helps visualize:

Executive business KPIs
Customer purchasing behavior
Product performance
State-wise revenue
Sales trends
Payment preferences
